# Neon Vector Arcade Pack Vol. 1

By Small Bright Assets

Reusable neon arcade assets for Asteroids-like games, retro shooters, jams, prototypes, menus, and overlays.

## Contents

- 6 transparent PNG player ships
- 4 transparent PNG UFO/enemy ships
- 18 transparent PNG asteroids in small, medium, and large sizes
- 3 projectiles
- 3 shield rings
- 8 explosion frames
- HUD panel, life icon, and blank wave banner
- 3 full HD neon grid backgrounds at 1920x1080
- sprite sheets for ships, UFOs, asteroids, and explosions
- preview cover image

## Folders

- `assets/ships`
- `assets/ufos`
- `assets/asteroids`
- `assets/projectiles`
- `assets/shields`
- `assets/explosions`
- `assets/hud`
- `assets/backgrounds`
- `assets/sheets`
- `preview`

## Usage

These assets are PNG files with transparent backgrounds except the full-screen backgrounds and preview images.

Suggested use:

- ships, UFOs, asteroids: 256x256 sprites
- projectiles: 96x96 or 160x64 sprites
- shields: 256x256 overlay effects
- explosions: 256x256 animation frames
- backgrounds: 1920x1080 scene backdrops
